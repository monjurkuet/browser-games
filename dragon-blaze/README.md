## Run

```bash
cd dragon-blaze
node server.js
```

Then open **http://localhost:8154/** in a browser.

## Requirements

- Node.js 18+
- Modern browser with WebGL2, WebAssembly, ES Modules support
- Must run via HTTP (not `file://`)
