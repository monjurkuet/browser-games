## Run

```bash
cd farm-slot-port
node server.js
```

Then open **http://localhost:8135/** in a browser.

## Requirements

- Node.js 18+
- Modern browser with WebGL2, WebAssembly, ES Modules support
- Must run via HTTP (not `file://`)
