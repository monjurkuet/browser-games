## Run

```bash
cd crazy-monkey-slot-machine
node server.js
```

Then open **http://localhost:8824/** in a browser.

## Requirements

- Node.js 18+
- Modern browser with WebGL2, WebAssembly, ES Modules support
- Must run via HTTP (not `file://`)
